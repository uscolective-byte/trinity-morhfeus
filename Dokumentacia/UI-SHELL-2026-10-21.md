# Čitateľnejšie UI Trinity

Upravené sú existujúce HTML/JS/CSS, bez zmeny API alebo rolí.
- Čitateľnejšie popisy, formuláre, chat a ovládacie prvky; väčšie klikateľné plochy.
- Pod 1100 px ponuka Účet a nástroje rozbalí hlavičku; zavrie sa kliknutím mimo, Escape alebo navigáciou.
- Aktívna navigácia má aria-current; pridaný skip link a viditeľný focus.
- Nastavenia majú sticky vyhľadávanie a horizontálne posúvateľné kategórie.
- Mobilná spodná navigácia je posúvateľná, rešpektuje safe area a chat má ohraničený vnútorný scroll.
- Pripravenosť schopností má plnú šírku. Zachované sú svetlý/tmavý režim a reduced-motion.

Overená môže byť syntax a unikátne HTML ID. Bez dostupného browsera/executora nie je potvrdený vizuálny vzhľad, reflow ani klikacie testy. Zmena v PR nie je potvrdené živé nasadenie.
